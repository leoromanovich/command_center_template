# План: название фичи

## Цель и границы

Ожидаемое поведение, ограничения, условия совместимости.

## Карта влияния

| Репозиторий | Изменения | Зависимости | Проверки |
|---|---|---|---|
| core | Контракт и реализация | app использует контракт | format, formatCheck, lint, test |
| app | Использование контракта | core из worktree этой фичи | format, formatCheck, lint, test |

## Выполнение

1. Изменить контракт и тесты core.
2. Обновить app и обработку ошибок.
3. Проверить совместную сборку с зависимостями из worktree фичи.

## Приёмка

- Конкретные наблюдаемые результаты.
- Сценарии ошибок и регрессий.

## Внешние действия

Создание MR: выключено. Изменение Jira: выключено. Если действия согласованы, описать точные репозитории, целевые ветки, содержание комментария и разрешённый переход статуса; затем включить соответствующие поля task.json.
