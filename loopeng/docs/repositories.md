# Репозитории и карта влияния

Рабочие репозитории пока не подключены. Заполните `repositories` в `cc.config.json` или `cc.local.json`, затем опишите их здесь.

Для каждого репозитория укажите source checkout, назначение, связи с другими репозиториями, базовую ветку, toolchain, команды сборки и проверок. Пути на конкретной машине храните в `cc.local.json`. Примеры из `examples/` подключаются только явным действием пользователя.

| Репозиторий | Ответственность | Зависит от | Базовая ветка | Сборка и проверки |
|---|---|---|---|---|

Для каждой задачи перечислите затронутые репозитории, изменяемые контракты и порядок внедрения. Рабочие ветки: `feature/<task>`, worktree: `WorkTree/<task>/<repo>`.

База ветки должна содержать нужный код в коммитах. Незакоммиченные изменения другого checkout в новый worktree не попадут. Завершённый результат предыдущей задачи публикуется локальным commit через её карточку; затем новую задачу можно базировать на этой ветке.

Крупные зависимости собирайте в слоях Docker-образа. Сборку изменяемой части направляйте в `/build`; конкретные команды задаются в профиле. Дополнительные инструменты и правила добавляются до утверждения плана.
