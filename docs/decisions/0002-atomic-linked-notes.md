# Атомарные связанные заметки

## Контекст

Монолитная документация расходует контекст модели и быстро устаревает. Полнотекстовый поиск не объясняет, какие знания связаны причинно.

## Решение

Использовать Obsidian-compatible Markdown с обязательными metadata, evidence и relations. Индексы служат картой, а не энциклопедией.

## Последствия

- Агент загружает только локальный подграф.
- Связи и свежесть можно валидировать.
- Создание заметки требует больше дисциплины.
- Производный граф можно добавить позже без смены источника истины.
